---

在 [`void.config.ts`](/docs/config) 中用 `routing.redirects` 字段定义 URL 重定向。键是来源 URL 模式，值是目标字符串，或带显式状态码的对象。

```json
{
  "routing": {
    "redirects": {
      "/old": "/new",
      "/blog/*": { "to": "/posts/:splat", "status": 301 }
    }
  }
}
```

## 规则

- **来源模式**以 `/` 开头。`*` 匹配任意字符，包括 `/`。
- **目标**可以是字符串（默认 `302`），也可以是包含 `to` 与可选 `status` 的对象。支持的状态码：`301`、`302`、`303`、`307`、`308`。
- 目标中的 `:splat` 会被替换成来源模式里 `*` 匹配到的那段路径。
- 目标自带的查询串会合并进 `Location` 头部（同名键以目标的参数为准）。想丢弃请求带来的查询串，就写一个显式的重置，例如 `?`。
- 要从处理器、loader 或中间件里发起重定向，请使用 [`c.redirect()`](/docs/reference/api/rewrites)，它只会发送你给定的地址，不会附加请求的查询串。具名 action 重定向到 GET 时会保留自己的查询参数，并丢掉 action 键。
- 多条规则命中时，**第一条命中的生效**。请把具体的模式写在 catch-all 模式之前。
- 重定向在请求到达 worker **之前**求值，因此会直接跳过静态资源服务、ISR 和 SSR。

## 域名级重定向

给来源加上 `https://host` 前缀，就只对访问该域名的请求做重定向：

```json
{
  "routing": {
    "redirects": {
      "https://www.example.com/*": "https://example.com/:splat",
      "https://old-marketing.com/*": "https://example.com/:splat"
    }
  }
}
```

`_redirects` 文件接受同样的语法：

```text
https://www.example.com/*  https://example.com/:splat  301
```

只写路径的来源会作用于项目的所有域名；带主机前缀的来源只作用于指定的那个域名。

来源必须使用 `https://` 加一个字面主机名，不能带通配符或端口。部署该规则之前，先用 `void domain add` 把域名加到项目里。仍在等待证书验证的域名，会在生效之后开始重定向。

## HTTP 转 HTTPS

设置 `routing.alwaysUseHttps` 可以把 HTTP 请求重定向到 HTTPS：

```ts title="void.config.ts"
import { defineConfig } from 'void/config';

export default defineConfig({
  routing: {
    alwaysUseHttps: true,
  },
});
```

Void 返回永久的 `308` 重定向，保留路径、查询串和请求方法。该选项默认是 `false`。localhost 与回环地址会保持 HTTP，方便本地开发和预览。

这个选项要求 Cloudflare 目标，对两种部署平台上的 Void 应用与静态站点都有效。

直接部署到 Cloudflare 时，请同时在 zone 上开启 [Always Use HTTPS](https://developers.cloudflare.com/ssl/edge-certificates/additional-options/always-use-https/)，以覆盖由 Cloudflare 直接服务的资源。

对于直接部署到 Cloudflare 的 SvelteKit、Nuxt、Astro、Analog、TanStack Start、React Router 或 vinext，请在框架或 Cloudflare zone 里配置 HTTPS；它们的静态构建（用 `--dir` 或 `inference.appType` 部署）才使用 `routing.alwaysUseHttps`。

## 框架的 `_redirects` 文件

Void 会读取受支持框架产出的 `_redirects` 文件，你也可以把它放在 Vite 的 `publicDir` 里：

```text
/old-page  /new-page     301
/blog/*    /posts/:splat 301
```

`void.config.ts` 中的规则优先于文件里的规则。`200` 表示 fallback，`200!` 表示[rewrite](/docs/edge/rewrites)；重定向不需要 `!` 后缀。
