## 创建应用

在一个空目录中，安装 Void 并运行初始化：

```bash title="npm"
npm install -D void
npx void init
```

```bash title="pnpm"
pnpm add -D void
pnpm void init
```

```bash title="yarn"
yarn add -D void
yarn void init
```

```bash title="bun"
bun add -D void
bunx void init
```

选择你的 UI 框架、起始模板与部署目标。Vite+ 是默认的构建工具。D1 是一个很好的首选数据库：它不需要单独运行数据库服务就能在本地工作。选择 Cloudflare 即可部署到你自己的账户，或者暂时跳过部署配置。

<Callout type="tip" title="不需要全局安装 Vite+">
  初始化流程会为你安装它，并保留你现有的包管理器配置与锁文件。
</Callout>

使用 pnpm 时，`pnpm create void my-app` 会同时创建项目目录并配置原生的构建权限。

## 在本地运行

```bash
npm run dev
```

打开 `http://localhost:5173`。在 Pages 起始模板中，`pages/` 放你的 UI，配套的 `.server.ts` 文件放它们的服务端 loader 与 action。Loader 把数据作为带类型的 props 返回给页面组件。

## 调用一个服务端路由

编辑 `routes/api/hello.ts`；如果你的模板里没有这个文件，就新建一个：

```ts title="routes/api/hello.ts"
import { defineHandler } from 'void';

export const GET = defineHandler(() => {
  return { message: 'Hello from Void' };
});
```

访问 `http://localhost:5173/api/hello` 看看响应。在客户端代码中，用 Void 的类型化 fetch 调用它：

```ts
import { fetch } from 'void/client';

const { message } = await fetch('/api/hello');
```

文件路径定义了 URL，处理器定义了响应类型。修改处理器中的 `message`，TypeScript 会用新的结构检查客户端。

<Callout type="info" title="数据库">
  数据库起始模板还包含 `db/schema.ts`。它的 Drizzle schema 定义了你的表与查询类型；Void
  会运行一个本地数据库，并在部署时为你开通一个真实的。
</Callout>

## 部署

如果你在初始化时选择了目标：

```bash
npx void deploy
```

如果当时跳过了部署配置，选择你的 Cloudflare 账户：

```bash
npx void deploy --platform cloudflare
```

Void 会在需要时打开浏览器让你登录，构建应用、开通资源、执行迁移，然后打印出部署地址。之后的部署会使用已保存的目标。团队平台、CI 与回滚参见[部署](/docs/deployment)。

## 把 Void 加入已有的 Vite 项目

用上面同样的包管理器命令安装 Void 并运行 `void init`。初始化流程会把 `voidPlugin()` 加入你的 Vite 配置，并创建其余的项目文件。如果配置需要手动修改，CLI 会把需要做的改动打印出来。

对于 TanStack Start、React Router 或 SvelteKit 这类元框架，请阅读对应的[框架集成指南](/docs/frameworks)。
