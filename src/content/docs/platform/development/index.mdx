title: 开发 Void 平台
description: 在本仓库中修改平台、在本地测试，并部署由你的 fork 构建出的运行时。
---

框架、CLI 与平台位于同一个仓库中。你可以修改平台、在本地测试它，并把由你的 fork 构建出的运行时部署到自己的 Cloudflare 账户里。

如果你只想运行已发布的平台、不改动它的实现，请从[安装 Void 平台](/docs/platform)开始。管理一个已安装的平台请参见[平台管理](/docs/platform/administration)。
