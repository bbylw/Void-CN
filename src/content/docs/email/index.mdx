---

用 Void 发送事务性邮件、在路由处理器中接收消息，以及在本地收件箱里测试外发邮件。

| 指南             | 适用场景                                       |
| ---------------- | ---------------------------------------------- |
| [发送邮件](/docs/email/sending)   | 发送邮件与附件、处理错误、在本地测试投递。     |
| [接收邮件](/docs/email/receiving) | 路由进来的消息、回复、转发、测试处理器。       |
| [域名与配置](/docs/email/domains) | 在平台上注册域名，或配置你自己的 Cloudflare 账户。 |

在启用了邮件能力的 Void 平台上，从它的[共享发件人](/docs/email/sending)开始。直接部署到 Cloudflare 的话，先[配置发件人与域名](/docs/email/domains)。
