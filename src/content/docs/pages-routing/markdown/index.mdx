在 `pages/` 中添加 `.md` 文件就是 Markdown 路由。页面继承布局、渲染为 HTML，只为[岛屿](/docs/pages-routing/islands)、客户端脚本与代码复制按钮发送 JavaScript。

## 安装与配置

把 `@void/md` 与你的框架适配器一起安装：

```sh title="React"
npm install @void/md @void/react
```

```sh title="Vue"
npm install @void/md @void/vue
```

```sh title="Svelte"
npm install @void/md @void/svelte
```

```sh title="Solid"
npm install @void/md @void/solid
```

把插件加进 Vite 配置，位置必须在框架适配器**之后**：

```ts title="React"
// vite.config.ts
import { voidMarkdown } from '@void/md/plugin';
import { voidReact } from '@void/react/plugin';
import { defineConfig } from 'vite';
import { voidPlugin } from 'void';

export default defineConfig({
  plugins: [voidPlugin(), voidReact(), voidMarkdown()],
});
```

```ts title="Vue"
// vite.config.ts
import { voidMarkdown } from '@void/md/plugin';
import { voidVue } from '@void/vue/plugin';
import { defineConfig } from 'vite';
import { voidPlugin } from 'void';

export default defineConfig({
  plugins: [voidPlugin(), voidVue(), voidMarkdown()],
});
```

```ts title="Svelte"
// vite.config.ts
import { voidMarkdown } from '@void/md/plugin';
import { voidSvelte } from '@void/svelte/plugin';
import { defineConfig } from 'vite';
import { voidPlugin } from 'void';

export default defineConfig({
  plugins: [voidPlugin(), voidSvelte(), voidMarkdown()],
});
```

```ts title="Solid"
// vite.config.ts
import { voidMarkdown } from '@void/md/plugin';
import { voidSolid } from '@void/solid/plugin';
import { defineConfig } from 'vite';
import { voidPlugin } from 'void';

export default defineConfig({
  plugins: [voidPlugin(), voidSolid(), voidMarkdown()],
});
```

## 页面的组成部分

一个 markdown 页面有三个可选部分：script 块、frontmatter 与正文。

```md
<script>
import Counter from "../components/Counter.vue" with { island: "visible" }
</script>

---

title: Getting Started
description: Learn how to use Void

---

# Getting Started

Welcome to Void. Here's an interactive demo:

<Counter />
```

- **`<script>` 块**：在 markdown 编译之前被提取出来。岛屿导入使用 `with { island: "..." }` 语法（参见[岛屿](/docs/pages-routing/islands)）。组件文件要用你框架的扩展名（`.vue`、`.tsx` 或 `.svelte`）。块里的其他代码会变成在浏览器中运行的[客户端脚本](#客户端脚本)。
- **frontmatter**：`---` 围栏之间的 YAML 元数据。布局与岛屿可以通过 [`useFrontmatter()`](#读取-frontmatter) 读取它。
- **正文**：标准 markdown 加上 GFM。形如 `<Counter />` 的大写标签引用导入的组件，渲染为岛屿。

## 客户端脚本

`<script>` 块用来放岛屿导入与页面加载时执行的 JavaScript。组件导入要用你框架的扩展名（`.vue`、`.tsx` 或 `.svelte`）：

```md
<script>
import Counter from "./Counter.vue" with { island: "visible" }
import { format } from "date-fns"

document.querySelector('.date').textContent = format(new Date(), 'PPP')
</script>

# My Post

<Counter />

Published: <span class="date"></span>
```

只有当前页面的客户端脚本会被加载。没有客户端代码的页面不需要任何额外脚本。

## 文件结构

Markdown 页面与常规页面一起放在 `pages/` 中，路由规则相同：

```text title="pages/（以 Vue 为例）"
├── layout.island.vue
├── index.island.vue
└── docs/
    ├── layout.island.vue    docs 布局（侧边栏、目录）
    ├── getting-started.md
    ├── configuration.md
    └── guides/
        └── deployment.md
```

`.md` 文件会继承布局，可以搭配 `.server.ts` 配套文件提供动态数据，静态时[自动预渲染](/docs/edge/prerendering)。规则与其他页面完全相同。

## 读取 frontmatter

在布局组件中用 `useFrontmatter()` 读取当前页面的 frontmatter：

```tsx title="React"
import { useFrontmatter } from '@void/md';

export default function DocsLayout({ children }) {
  const fm = useFrontmatter();
  return (
    <div>
      <h1>{fm.title}</h1>
      {children}
    </div>
  );
}
```

```vue title="Vue"
<script setup lang="ts">
import { useFrontmatter } from '@void/md';

const fm = useFrontmatter();
</script>

<template>
  <h1>{{ fm.title }}</h1>
  <slot />
</template>
```

```svelte title="Svelte"
<script>
import { useFrontmatter } from "@void/md";

const fm = useFrontmatter();
</script>

<h1>{fm.title}</h1>
<slot />
```

```tsx title="Solid"
import { useFrontmatter } from '@void/md';

export default function DocsLayout(props) {
  const fm = useFrontmatter();
  return (
    <div>
      <h1>{fm.title}</h1>
      {props.children}
    </div>
  );
}
```

岛屿组件同样可以调用 `useFrontmatter()`。带岛屿页面的 frontmatter 请保证是可以公开给浏览器的。

## 页面虚拟模块

导入 `@void/md/pages`，在构建期拿到所有 markdown 页面的元数据，用来搭建侧边栏、导航或搜索索引：

```ts
import pages from '@void/md/pages';
// [{ path: "/docs/getting-started", title: "Getting Started", frontmatter: {...}, headings: [...] }, ...]
```

该列表遵循[页面环境后缀](/docs/pages-routing)规则：`debug.dev.md` 在开发环境中以 `/debug` 出现。

每个条目的形状如下：

```ts
interface MdPage {
  path: string; // 路由路径
  title: string; // 来自 frontmatter.title 或第一个 h1
  frontmatter: Record<string, unknown>; // 完整解析后的 frontmatter
  headings: { depth: number; slug: string; text: string }[]; // 提取出的标题
}
```

数组按路径排序；开发环境中 `.md` 文件新增、删除或修改时，它会随 HMR 更新。

## 默认 CSS 主题

markdown 插件提供一个精简的 CSS 主题，有两个入口：

### 完整主题（reset + 基础样式 + 内容样式）

需要完整样式表的独立 markdown 站点用它。它包含现代 CSS reset、基础正文样式与全部 markdown 内容样式：

```css
@import '@void/md/theme.css';
```

### 仅内容样式（限定在 `.void-md` 作用域）

已有自己的 reset 与全局样式、要把 markdown 嵌入现有应用的场景用它。它只包含作用于 `.void-md` 的内容样式：

```css
@import '@void/md/theme-content.css';
```

### 用法

把 markdown 内容包在 `.void-md` 元素里，让样式限定其作用：

```html
<main class="void-md">
  <slot />
</main>
```

主题覆盖：

- **正文排印**：标题、段落、列表、引用、表格、行内代码、链接、水平分隔线、任务列表、`<kbd>`、`<mark>`、定义列表与脚注。暗色模式通过 `prefers-color-scheme` 与 `data-theme` 属性生效。
- **代码块**：双主题语法高亮，用 CSS 切换、零 JavaScript。
- **容器**：`:::tip`、`:::warning`、`:::danger`、`:::info` 与 `:::details` 的样式。
- **GitHub 提示块**：支持 `> [!NOTE]`、`> [!TIP]`、`> [!WARNING]` 等语法。

### CSS 变量

所有样式都可以通过设在 `.void-md` 上的 CSS 变量定制，改成你的品牌色即可：

```css
.void-md {
  --vmd-link: #8b5cf6;
  --vmd-link-hover: #7c3aed;
}
```

| 变量                | 亮色默认值                                                                     | 暗色默认值 | 说明                                                                   |
| ------------------- | ------------------------------------------------------------------------------ | ---------- | ------------------------------------------------------------------------ |
| `--vmd-font-body`   | `system-ui, -apple-system, "Segoe UI", Roboto, sans-serif`                     | 同默认     | 正文字体栈                                                               |
| `--vmd-font-mono`   | `ui-monospace, "Cascadia Code", "Source Code Pro", Menlo, Consolas, monospace` | 同默认     | 等宽字体栈                                                               |
| `--vmd-text`        | `#1a1a2e`                                                                      | `#e2e8f0`  | 主文本颜色                                                               |
| `--vmd-text-muted`  | `#64748b`                                                                      | `#94a3b8`  | 次要 / 弱化文本（引用、行号、脚注）                                      |
| `--vmd-link`        | `#2563eb`                                                                      | `#60a5fa`  | 链接颜色                                                                 |
| `--vmd-link-hover`  | `#1d4ed8`                                                                      | `#93bbfd`  | 链接悬停颜色                                                             |
| `--vmd-border`      | `#e2e8f0`                                                                      | `#334155`  | 边框（h2 下划线、表格、行内代码、`<kbd>`、水平分隔线）                   |
| `--vmd-bg-soft`     | `#f8fafc`                                                                      | `#1e293b`  | 柔和背景（表头、行内代码、代码块、`<kbd>`）                              |
| `--vmd-line-height` | `1.75`                                                                         | 同默认     | 正文行高                                                                 |

暗色取值通过 `prefers-color-scheme: dark`（自动模式）与 `[data-theme="dark"]`（显式切换）自动生效。想在偏好暗色的系统上强制亮色，在 `<html>` 上设置 `data-theme="light"`。

想完全掌控样式的用户可以不导入主题，自己写 CSS。

## Markdown 功能

Markdown 功能渲染为静态 HTML，代码复制按钮会附带一小段客户端脚本。

### 容器

```md
::: tip
Helpful advice here.
:::

::: warning
Watch out for this.
:::

::: danger
This will break things.
:::

::: info
Some context.
:::

::: details Click to expand
Hidden content here.
:::
```

自定义标题同样支持：`::: tip Pro Tip`。

### GitHub 提示块

```md
> [!NOTE]
> Useful information.

> [!TIP]
> Helpful advice.

> [!IMPORTANT]
> Key information.

> [!WARNING]
> Potential issues.

> [!CAUTION]
> Dangerous actions.
```

### 语法高亮

代码块默认用 `github-light` 与 `github-dark` 主题高亮。不受支持的语言的代码块会渲染为纯文本。

### 行高亮

在代码围栏的 meta 里用 `{lines}` 高亮指定行：

````md
```ts {1,3-5}
const a = 1; // highlighted
const b = 2;
const c = 3; // highlighted
const d = 4; // highlighted
const e = 5; // highlighted
```
````

### diff、聚焦与错误标记

用行内注释给行加标注：

```ts
export function hello() {
  console.log('old'); // [!code --]
  console.log('new'); // [!code ++]
  console.log('look here'); // [!code focus]
  console.log('problem'); // [!code error]
  console.log('careful'); // [!code warning]
}
```

代码块自带复制按钮。

### 行号

用 `:line-numbers` 为单个代码块启用行号：

````md
```ts :line-numbers
const a = 1;
const b = 2;
```
````

用 `:line-numbers=5` 从指定数字开始编号。

### Emoji

短代码会转换为 Unicode：`:tada:` 变成 🎉，`:rocket:` 变成 🚀。

### 脚注

在正文中引用脚注，定义可以放在文档任意位置：

```md
Here is a statement with a footnote.[^1]

[^1]: And here is the footnote body.
```

引用与定义会渲染成内容末尾带链接的脚注列表。

### 属性

给任意元素添加 class、ID 或属性：

```md
# Heading {.custom-class #my-id}

Paragraph with attributes. {.note}
```

### 导航与媒体

标题自带永久链接锚点；用 `[[toc]]` 插入目录；图片懒加载；`.md` 链接会解析为页面路由。

## 插件选项

```ts
import { voidMarkdown } from '@void/md/plugin';

voidMarkdown({
  themes: { light: 'github-light', dark: 'github-dark' },
  copyLabel: 'Copy Code',
});
```

| 选项        | 类型                              | 默认值                                             | 说明                                       |
| ----------- | --------------------------------- | ---------------------------------------------------- | ------------------------------------------ |
| `themes`    | `{ light: string; dark: string }` | `{ light: "github-light", dark: "github-dark" }`     | 代码块配色主题，如 `pierre-light` / `pierre-dark` |
| `copyLabel` | `string`                          | `"Copy Code"`                                      | 代码复制按钮的提示文字与无障碍标签         |

代码块语言无需额外配置。未知的主题名会让构建报错。

`shiki.themes` 选项已废弃，请改用 `themes`。

面向翻译站点时，把 `copyLabel` 设为站点语言的文案，例如中文站可设为 `'复制代码'`。

## 搭建侧边栏

用 `@void/md/pages` 挑选要进入侧边栏的页面：

```ts
import pages from '@void/md/pages';

const docPages = pages.filter((page) => page.path.startsWith('/docs/'));
```

为每个条目渲染 `page.path` 与 `page.title` 的链接；在布局里用 `useFrontmatter()` 显示当前页面的元数据；使用自带主题时，把内容包进 `.void-md`。
