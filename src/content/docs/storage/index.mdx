## 基本操作

```ts
import { storage } from 'void/storage';

// 上传
await storage.put('uploads/photo.jpg', file, {
  httpMetadata: { contentType: 'image/jpeg' },
});

// 下载
const object = await storage.get('uploads/photo.jpg');
if (object) {
  const data = await object.arrayBuffer();
}

// 删除
await storage.delete('uploads/photo.jpg');

// 列举
const listed = await storage.list({ prefix: 'uploads/' });
for (const obj of listed.objects) {
  console.log(obj.key, obj.size);
}

// 仅元数据
const head = await storage.head('uploads/photo.jpg');
```

`storage` 支持完整的 `R2Bucket` API。

## 分发文件

一个常见模式是通过 API 路由分发上传的文件：

```ts title="routes/files/[key].ts"
import { defineHandler } from 'void';
import { storage } from 'void/storage';

export const GET = defineHandler(async (c) => {
  const object = await storage.get(`uploads/${c.req.param('key')}`);

  if (!object) {
    return c.notFound();
  }

  const headers = new Headers();
  object.writeHttpMetadata(headers);
  headers.set('etag', object.httpEtag);
  // 不要让用户上传的 HTML 或 SVG 在你的站点上作为页面执行。
  headers.set('X-Content-Type-Options', 'nosniff');
  headers.set('Content-Disposition', 'attachment');

  return new Response(object.body, { headers });
});
```

<Callout type="warn" title="安全提示">
  用户上传的文件可能包含 HTML 或脚本。请把它们存放在由服务端决定的 key 下，并以 `nosniff` 与 `Content-Disposition: attachment` 分发。这样 `<img>` 与 `<video>` 标签仍然可以正常显示，而直接打开 URL 则会下载文件。
</Callout>

## 自定义绑定

用 `createStorage(bucket)` 接入你自己的 R2 绑定，或在测试中使用：

```ts
import { createStorage } from 'void/storage';

const storage = createStorage(env.MY_BUCKET);
```
